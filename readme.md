# Lotus-Plugin

本库已停更，仅保留迁移入口。

## 迁移到 Lotus-Yunzai

更新本插件并重启旧机器人后，由主人发送：

```text
#迁移荷花云崽
```

指令会在旧安装旁创建独立的 Lotus-Yunzai 目录，自动准备 Bun、子模块及依赖，迁移账号、签到设置和可兼容的数据，完成初始化后启动新机器人。正式导入前会停止旧机器人，防止重复执行任务；迁移、初始化或新端启动失败时尝试恢复旧机器人。旧目录与原始数据保留，不自动删除。

进度发送到当前会话，交接后的记录保存在安装旁的 `.lotus-yunzai-migration-<旧目录名>/` 私有目录。仅支持 Linux，运行用户须有安装旁目录的写权限，Git 必须可用。已有同名目录不会覆盖。

一代旧的迁二代指令已替换，不再需要多次确认或手动删除旧库。
